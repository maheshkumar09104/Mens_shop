# Mens Shop

MERN stack starter for a men's shopping website.

## Structure

```text
mens-shop/
  client/   React + Vite frontend
  server/   Node.js + Express API
```

## Run Locally

```bash
cd server
copy .env.example .env
npm install
npm run dev
```

```bash
cd client
npm install
npm run dev
```

The client runs on `http://localhost:5173` and proxies API requests to `http://localhost:5000`.
